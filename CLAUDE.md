# The Growth Edit

Content studio project. All Instagram content produced here — carousels and
Reels — must follow the brand's editorial design system.

## Design system

Canonical reference lives in `design-system/`:

- `design-system.md` — tokens, typography, spacing/grid, components,
  photography direction, and voice. Read this first for any visual work.
- `style-guide.html` — visual/interactive reference of the same system
  (open in a browser to see the tokens and components rendered).
- `carousels.md` — Instagram carousel build spec (canvas size, safe margins,
  slide types, HTML → PNG export workflow).
- `reels.md` — Instagram Reels build spec (canvas size, safe zones, cover
  frame, on-screen text and beat structure, HTML → PNG export workflow).

Always apply `design-system.md`'s tokens, type scale, and voice rules to any
new carousel or Reel; use `carousels.md` / `reels.md` for the format-specific
layout and export mechanics. Don't invent new colors, fonts, or layouts
outside this system without checking with the user first.
